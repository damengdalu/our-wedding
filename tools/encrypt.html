囍 Encrypt content

Generates the encrypted js/content.js from content/content.template.js.

Developer-only tool. Do not deploy this file to GitHub Pages — it imports the plaintext template. Run it locally (e.g. python3 -m http.server) so the template can load.
  1. Edit your content in content/content.template.js and save.
  2. Enter the password you’ll share with guests, then click Encrypt.
  3. Click Copy (or Download) and replace the contents of js/content.js.
  4. Commit & deploy. Test by opening index.html and entering the password.
